Cómo actualizar las noticias

Refresh vuelve a leer el archivo publicado. Para recopilar noticias nuevas:

  1. Abre el repositorio en GitHub.
  2. Ve a Actions.
  3. Selecciona Actualizar noticias y publicar dashboard.
  4. Pulsa Run workflow y confirma con Run workflow.
  5. Espera a que termine la publicación y pulsa Refresh aquí.
